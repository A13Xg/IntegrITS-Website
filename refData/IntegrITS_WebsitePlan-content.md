### Important Correction

Two source documents display the CAGE code as **1LVF22**. A CAGE code is five characters, and current federal/GSA data shows **1LVF2**. Use **1LVF2**.

### NAICS Presentation Guidance

The reports contain more than one NAICS code because IntegrITS performs work in different categories and holds contracts covering different scopes.

Recommended website presentation:

- **541330 — Engineering Services**
- **336611 — Ship Building and Repairing**
- Other codes should be taken directly from the company’s current SAM profile before publication.

Do not label a single NAICS code as universally “primary” across every contract vehicle without checking current SAM data.
